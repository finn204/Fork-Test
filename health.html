Steps/sleep didn't sync today? Type them in manually

Steps and sleep sync automatically from Apple Health via an iOS Shortcut — there's no direct web API into Health, so this is the real workaround. Weight is intentionally not part of this; log that manually above each morning. ~5 min to set up:

  1. Open the Shortcuts app → + to create a new shortcut.
  2. Find Health Samples Where → Type: Steps → filter: Start Date is today → leave the Limit toggle off (we want every sample, not just one).
  3. Calculate Statistics → Operation Sum → input the Health Samples from the step above. This is your total steps for today.
  4. Find Health Samples Where → Type: Sleep Analysis → filter: Start Date is in the last 1 days → Limit off.
  5. Calculate Statistics → Operation Sum, on Duration → input the sleep samples from the step above. This gives total sleep time — Shortcuts usually shows it as "X hr Y min"; if it doesn't come out as a plain number, tap the result variable and look for an option to express it in hours, or send Claude a screenshot.
  6. Add a Text action with this, replacing the two 0s with the step-count and sleep-hours variables from above (tap into the text, tap where a 0 is, pick the matching variable): {"secret":"tnXe1XJY8iymOfgo6JEc9kvKYZMA5D61","steps":0,"sleepHours":0}
  7. Add Get Contents of URL: URL https://fork-test-rose.vercel.app/api/health-sync, Method POST, Request Body JSON set to the Text from the previous step.
  8. Rename the shortcut (e.g. "Sync Health") → Automation tab → + → Time of Day (e.g. 9pm daily) → Run Immediately so it doesn't ask each time → choose this shortcut.
